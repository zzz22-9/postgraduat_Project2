1. 提前 15 分钟接好电源，确认电脑不会在汇报期间自动睡眠；不要临场更新代码、Python 或依赖。

## 现场突然无法访问

1. 再次双击 **启动演示.cmd**。若是后台退出且端口空闲，会重新启动；健康服务不会重复启动。
2. 若提示端口冲突或检查失败，不反复点、不盲目结束进程。直接打开 **离线演示.html** 继续讲输入、排队、返修和结果，并说明切换到已保存实验。
3. 会后保留 `logs/last-check.json`、`logs/last-launch.json` 和对应 `server-*.log` 排查。端口被其他服务占用、进程卡住、依赖缺失会明确失败，不会假报成功。

## 使用边界

- 地址为 http://127.0.0.1:8000/，只能在运行服务的这台电脑使用。外网断开不影响本地系统；其他电脑上的 127.0.0.1 指向其自身。
- 新启动的后台与聊天/启动窗口分离，但电脑关机、注销、进程崩溃、系统休眠仍可中断服务。工具不安装系统服务、不设置开机启动，也不会持续监控或自动重启。
- 服务意外停止时，正在运行的仿真可能中断；查看历史状态后复制参数重跑，不把中断结果当作完成。
- 已有默认/返修实验在 `data/erp.simulations/`；离线页从这两个保存批次生成，没有新跑实验。需要重新导出时运行 `.\.venv\Scripts\python.exe -B tools\export_demo.py`。
- 本地代码和 .venv 移到其他电脑后不保证可直接运行；换电脑应提前按 README 安装并完整彩排。离线 HTML 可直接复制使用。
